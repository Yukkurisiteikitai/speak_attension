# ADR 0027: 未使用のWebSocket中継を撤去しローカルAPIを制限する

## 背景

会議の発話原文を含むセッションログがWebSocketで全接続に中継されていた。画面側には受信処理がなく、会議状態と表示用ログはブラウザー内のストアに保持されている。ローカルHTTP APIもOriginと本文サイズを検証していなかった。

## 決定

- WebSocket中継と接続状態表示を撤去する。セッションログは既存のブラウザーストアで保持する。
- ローカルHTTP APIは127.0.0.1で待ち受け、5173番の開発画面のOriginとJSON形式を要求する。Viteは5173番が使えない場合に別ポートへ移らない。
- 本文サイズ、送信頻度、ログ保存量を制限する。Discordへの長いレポートは番号付きで分割し、成功件数と途中失敗を画面に示す。

## 影響

別サイトからブラウザー経由でローカルAPIを呼ぶ経路と、会議ログを任意のWebSocket接続へ転送する経路を閉じる。Origin検証はローカルプロセスの認証ではない。Discordとブラウザー音声認識の外部通信は利用者向け文書に明記する。
