# ADR 0016: 明示的な確認・改善フェーズと残り時間による質問選別

- 日付: 2026-09-11
- 状態: 採用

## 背景

発言ごとに不足点の質問を表示すると、議論の途中に自動介入される。ファシリテーターが確認・改善に入るタイミングを選び、その時の残り時間で確認を進めたい。

## 判断

議論中は不足点をルールで内部更新するが、進行マップの質問・条件付き予定と質問のAIレビューを停止する。明示的な開始操作で残り時間を設定し、未確認の前提・未解決質問、決定、担当・期限の順に選別する。1問1分を目安に最後の2分を振り返りへ確保する。回答・保留で次の問いへ進み、未回答を自動的に完了にしない。

最終確認では決定と変更・回答を振り返り、決定理由、認識のずれや漏れ、持ち越しの確認を手動記録する。未回答・保留を残し、記録をMarkdownとJSONに含める。新しい発言やアクション更新で確認内容が古くなった場合は再確認する。進行状態は会議ストアで所有する。

質問の具体化には既存のLM Studio非同期処理を使い、未設定・失敗時はルール提案を維持する。質問提示以外のライブ発言処理は変更しない。

## 帰結

時間配分・優先度はルールによる目安で、合意や認識一致の自動判定ではない。短時間の場合は最終確認を優先し、残りを持ち越す。議論への復帰と残り時間の再設定を可能にする。永続化や音声によるフェーズの自動切替は追加しない。
