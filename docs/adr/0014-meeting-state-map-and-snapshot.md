# 0014: 現在状態から出典へたどるマップとスナップショット

Date: 2026-09-11
Status: accepted

## 決定

p.md の「会議の任意の瞬間に、何が決まり、何が未決で、誰が何をすべきかと根拠を取得する」を、既存の決定グラフとアクション更新機能の拡張として実装する。アイデア出しを主モードとする構成は維持する。

会議の中央に現在アクションと未決定項目を示し、選択ノードとその直接の参照先のみを表示する。深いグラフは一段ずつ進み、全文は隣接する原文欄で読む。全ノード一覧から、アクションに接続されていない課題・決定・発言も選択できる。固定サイズのプレビューは短縮し、原文・エクスポートは短縮しない。

課題ノードと質問・提案への逆参照を追加する。担当・期限・優先度は既存アクション属性を再利用し、独立ノードの重複状態は作らない。手動更新は対象IDと理由を必須とし、変更前後の属性を結果ノードへ保持する。元発言と手動記録は区別する。関連線は規則による候補として表示し、事実確認済みの因果関係とは呼ばない。

ブラウザー内の純粋関数を状態処理の実装層とし、サーバーへの会議状態の二重管理やDBを導入しない。任意時点で全出典を含むJSONと参照付きMarkdownをダウンロードできる。モード切替で会議を破棄せず、隠れた会議の音声認識・ファイル再生は停止する。

## 範囲

音声は録音しないため出典の終点は原発言テキストと提供された時刻・発言者である。クラウドLLM、話者推定、自動完了・撤回推定、スナップショットのインポートは追加しない。従来のライブマップ、整理、抜け漏れレポートは引き続き使える。
