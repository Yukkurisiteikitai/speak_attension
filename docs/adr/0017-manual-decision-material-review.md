# ADR 0017: 手動の判断材料レビューと根拠・推論の分離

- 日付: 2026-09-16
- 状態: 採用

## 背景

未言及項目を一般論として警告すると、会議を中断し、存在しない不足を決定してしまう。目的は、現在の選択を変え得る条件を根拠付きで確認できるようにすること。

## 判断

会議のリアルタイム処理は変更せず、ファシリテーターが明示的に起動する判断材料レビューを追加する。初期実装は、公開・導入等の実行文脈と、不具合・品質等の実際の懸念が両方ある場合だけ、対応体制、公開範囲、価値判断を候補にする。各候補は確認済み発言、推論、会話からは分からない情報、条件付き仮説、根拠発言IDを別々に保持する。

候補は参加者の提案・決定ではない。処理済み状態を会議メモリ内に保持し、同じ前提では再提示せず、根拠となる前提が変化した場合だけ再確認にする。根拠を十分に特定できない場合は「解析不能」と表示し、安全や漏れなしを主張しない。

## 帰結

初期の規則は狭く、すべての会議類型をカバーしない。LLMによる高度化を行う場合も、LM Studioのみを使い、実在する根拠IDの検証と同じ状態モデルを必須とする。
