# 0012: 決定の理由と原発言を段階的にたどる

Date: 2026-09-09
Status: accepted

## 決定

既存の会議ストアと独立した決定グラフを維持し、リアルタイムのルールで一般的な提案・明示的な決定・因果節を増分抽出する。「なので、」「だから、」などで理由と行動を分け、原発言は全文で保存する。疑問・否定・仮定を決定に昇格させず、推測の理由・リスクは未確認として扱う。明示的な話題転換以降だけを接続候補とする。

アクションから決定・理由・根拠・原発言へ一段ずつ開く。元発言の時刻と提供された発言者を表示し、担当者と判断した発言者を区別する。発言者の推測や話者分離は行わない。未決定の提案・質問・未確認項目も折りたたみ表示する。

## 制約

意味理解ではなくルールによる近接発言の関連付けであり、暗黙の話題転換や複雑な否定は完全には判定できない。緊急性の理由がない場合は未確認表示を維持する。LLM・クラウド通信・永続化は追加しない。質問の回答による自動解決、決定撤回やアクション完了の状態更新は今後の対象とする。
