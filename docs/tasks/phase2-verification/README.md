# Phase 2 ブラウザ検証（2026-09-28）

merge 前に localhost で実際にブラウザを動かして確認した記録。
`npm run check` / `npm run build` は DOM をレンダリングしないため検出できない、
不正な HTML 構造と未定義 CSS クラスの2件をこの検証で発見・修正した
（commit `5a5909c`）。

## 実行方法

Playwright はプロジェクトの `package.json` に追加していない
（依存追加の制約に触れるため）。スクラッチパッケージへ一時的にインストールして実行した。

```sh
npm run dev:client &            # http://127.0.0.1:5173/
mkdir -p /tmp/pw-runner && cd /tmp/pw-runner
npm init -y && npm install --no-save playwright@1.63.0
npx playwright install chromium --with-deps   # 初回のみ
cp <このディレクトリ>/verify-timeline.mjs .
node verify-timeline.mjs
```

`verify-timeline.mjs` は7発話を投入し、タイムラインの表示・意味単位への分割・
修正メニュー・タブ切替後の永続性を自動検証してスクリーンショットを撮る。

## この検証で見つけて直した2件

1. `<button>` の中に `<select>` を入れていた（不正HTML、修正メニューの操作が信頼できない状態）
2. 新しく出力していたCSSクラス5件（`timeline-units` 等）に定義が無く、意味単位が無装飾で並ぶ状態だった

いずれも `npm run check` では検出できず、実ブラウザでの描画確認で見つかった。

## 既知の表示上の注意点（バグではない）

「保留」「検討中」の行は意味ラベルが「選択肢」と表示される。`parseAxes.ts` の
設計で、両方とも一旦 "option" として扱い、発話行為（defer/report）と確定度
（deferred/considered）で区別している。意図的だが、ラベルだけ見ると分かりにくい
可能性がある。UI表現の調整余地として残す。
